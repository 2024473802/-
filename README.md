# 云杉科技企业官网示例

响应式、多终端适配的企业官网示例，包含首页、产品与联系模块，并提供 Node.js Mock API 以便前后端联调。

## 功能亮点
- HTML5 + CSS3 响应式布局，支持桌面端、平板与移动端
- JavaScript 交互：导航折叠、主题切换、动态产品渲染
- Node.js 提供 `/api/products` 与 `/api/contact` 模拟接口

## 快速开始
```bash
npm install   # 无额外依赖，可跳过
npm start     # 默认运行在 http://localhost:3000
```

## 目录
- `public/`：前端静态资源
- `server.js`：静态资源与 Mock API 服务
- `docs/requirements.md`：需求分析与测试用例

更多细节见文档与代码内注释。
